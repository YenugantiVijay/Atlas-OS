Windows installation

  1. Open this application over HTTPS in an updated Chrome or Microsoft Edge browser.
  2. In Edge, choose Menu → Apps → Install this site as an app. In Chrome, choose Menu → Cast, save, and share → Install page as app, or the address bar installation icon.
  3. Follow the browser prompt. Launch Atlas OS from Start or your browser's app list where supported.

Menu wording varies by browser version. Installation remains available through browser menus when no automatic prompt appears.

Requirements and version

A supported, updated browser, JavaScript, browser storage, and an internet connection for business operations. Desktop, tablet, and mobile layouts use the existing responsive application.

Application version: loading. Native desktop installers are planned.

Updates

Save your work and close every Atlas OS window to activate a downloaded update. Reopen while online. This application does not force a reload while you are working.

Troubleshooting and FAQ

No installation button? Use Chrome or Edge's menu, check HTTPS, and check whether Atlas OS is already installed. Browser policy or private browsing may prevent installation.

Can I work offline? This release is online-first. The offline screen contains no financial records. An already-open workspace may retain pending drafts; they are not proof of a posted transaction.

Connection restored? Retry the workspace. Check pending requests before repeating a transaction.

Is this a Windows installer? It is a browser-installed PWA. A native .exe or .msi is not available.
