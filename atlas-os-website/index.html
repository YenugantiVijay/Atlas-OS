Atlas OS Website Preview

This index.html is a lightweight preview entry for VS Code Live Server or a browser. The complete website is built with Astro, so a plain HTML file cannot render its dynamic pages.

Windows: Double-click preview-website.cmd in this folder to start live development mode with auto-refresh. Or open a terminal here and run npm run dev.

Open Live Website ↗ If the button cannot connect, start the dev server first. Production homepage: dist/index.html after npm run build. This launcher is not part of the deployed website.
